GIT COMMAND DOCUMENTATION — QUESTION 1
Project: BrightPath Git Workflow
Public repository: https://github.com/not-so-shubh/brightpath-git
Working environment: local Mac Terminal; repository initialized locally before GitHub publication.

The entries below reproduce the Git commands used for this assignment. Some verification commands were run more than once. HTML changes, Python editing, and shell file/folder operations are not Git commands.

01. git --version
    Verify that Git is installed and display its version (2.52.0 on this Mac).

02. git init -b main
    Initialize the local repository with its first branch named main.

03. git status
    Inspect the working tree and identify untracked, staged or modified files; repeated throughout the exercise.

04. git add index.html about.html
    Stage both HTML files before the initial commit.

05. git commit -m "Initial commit: Add homepage and about page"
    Save the original site files as the root commit (bf71a77).

06. git log --oneline
    View a concise list of commits and their abbreviated hashes.

07. git diff
    Inspect unstaged modifications in an HTML file before committing.

08. git add index.html
    Stage a changed homepage for the second commit and later for the HTML correction.

09. git commit -m "Update homepage with Git learning introduction"
    Record the second change to the homepage on main (4a87cb7).

10. git branch feature
    Create the separate feature branch from the current main commit.

11. git switch feature
    Switch the working tree to the feature branch.

12. git branch
    Display local branches and identify the active branch with an asterisk.

13. git add about.html
    Stage the About page changes created on the feature branch.

14. git commit -m "Add feature branch improvements to about page"
    Save the feature branch work (49b928c).

15. git switch main
    Return to main before incorporating feature work.

16. git merge --no-ff feature -m "Merge feature branch into main"
    Merge feature into main using an explicit merge commit (a680467) to preserve branch history.

17. git log --all --oneline --graph --decorate
    Display the connected history of main and feature including commit IDs and branch labels.

18. git check-ignore -v debug.log temp/notes.txt
    Confirm that the *.log and temp/ rules in .gitignore exclude both test paths.

19. git add .gitignore
    Stage the newly created ignore-rule file.

20. git commit -m "Add gitignore rules for logs and temporary files"
    Save the .gitignore configuration as a separate commit (d675d21).

21. git log --oneline -5
    Inspect the five most recent commits after implementing .gitignore.

22. git add revert-demo.txt
    Stage a temporary file solely to demonstrate an undo operation.

23. git commit -m "Add temporary file to demonstrate Git undo"
    Record the additional temporary-file commit (5468439).

24. git revert --no-edit HEAD
    Create a new commit that undoes the last commit without rewriting history (011c321).

25. git log --oneline -7
    Show that both the temporary commit and its revert remain in the history.

26. git diff --check
    Check unstaged changes for trailing whitespace and similar formatting errors.

27. git diff -- index.html
    Inspect the specific change moving the homepage paragraph inside the HTML body.

28. git commit -m "Fix homepage HTML structure"
    Record the corrected homepage markup (a610a21).

29. git add git_commands.txt
    Stage this documentation file; used for its original commit and final correction.

30. git commit -m "Document Git commands used in assignment"
    Save the first version of the command documentation (4ca53da).

31. git log --oneline -3
    Verify the latest three commits after adding documentation.

32. git remote add origin https://github.com/not-so-shubh/brightpath-git.git
    Connect the already-initialized local project to the empty public GitHub repository.

33. git remote -v
    Verify the origin fetch and push URLs.

34. git push -u origin main
    Publish main to GitHub and configure origin/main as its upstream tracking branch.

35. git push origin feature
    Publish feature separately so both branches are visible on GitHub.

36. git branch -a
    List the local branches and the remote-tracking branches origin/main and origin/feature.

37. git status -sb
    Display a compact working-tree and upstream tracking summary; ## main...origin/main shows tracking.

38. git commit -m "Correct command log to match actual workflow"
    Save this corrected, assignment-specific command documentation as a new commit.

39. git push origin main
    Publish the final documentation correction to the existing main branch on GitHub.

ADDITIONAL REPOSITORY VERIFICATION
- The initial repository was created on the Mac before the remote was configured.
- Two source files were initially committed: index.html and about.html.
- The feature branch has a distinct commit and main has a genuine two-parent merge commit.
- .gitignore contains *.log and temp/; git check-ignore -v confirmed both rules.
- The undo test was committed then reverted; revert-demo.txt is absent and the working tree was clean.
- The public repository contains both main and feature branches.
